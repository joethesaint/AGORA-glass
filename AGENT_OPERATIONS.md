## 📜 2. Log Interpretation (The "Glass-Box" Trace)

Logs are dual-streamed: **Human-friendly (Stdout)** and **Machine-readable (logs/agent.jsonl)**.

### Situation A: Healthy Position
**Log:** `[info] position_fetch_success ... margin_ratio=0.35 leverage=3.0`
**Meaning:** The monitor successfully polled the exchange. The `RiskEngine` determined the position is safe (well above the 12% critical band).

### Situation B: Critical Risk Detected
**Log:** `[info] risk_verdict ... level=CRITICAL ... vol_factor=0.48`
**Meaning:** The `RiskEngine` detected a margin ratio below the dynamic threshold (which scales with market volatility). It has published a `RiskVerdict` to the MessageBus.

### Situation C: Reasoning Hash Generated
**Log:** `[info] reasoning_trace_generated ... reason_hash=0x91d3...`
**Meaning:** The `ReasoningTracer` captured the "why" behind the decision, hashed it, and is ready to pin it to the Arc Network. This is the core of the "Glass-Box" transparency.

### Situation D: Rescue Finalized
**Log:** `[info] rescue_complete ... final_tx_hash=0xSIMULATED_TX`
**Meaning:** The `RescueDispatcher` successfully coordinated with the `CircleRescuer` to move USDC collateral.

## 🛠️ 4. Important Notes & Troubleshooting

1.  **Windows Signals:** We implemented a fix for `NotImplementedError` on Windows. If you see `Shutdown signal received`, it means `KeyboardInterrupt` (Ctrl+C) was caught correctly.
2.  **Log File:** If the terminal is too fast, run `Get-Content logs/agent.jsonl -Tail 20` in a separate window to see the raw JSON data.
3.  **WebSocket:** The server starts on port **8765**. Ensure this port is open if the dashboard (Andy's part) cannot connect.
4.  **RPC Unauthorized:** If you see `unauthorized` when deploying contracts, your `arc-canteen` session may have expired. Run `arc-canteen shell-init`.
