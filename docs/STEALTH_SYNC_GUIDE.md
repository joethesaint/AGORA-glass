# Stealth Sync Protocol

This guide explains how to synchronize your "Shadow Work" between two PCs without ever pushing to the public GitHub repository.

## 1. The Strategy: Git Bundles
Instead of pushing to `origin`, we package our local branches into a single file called a **Git Bundle**. You can then move this file between PCs using a USB drive, private cloud (Google Drive, Dropbox), or even a private Discord DM.

## 2. Setting Up a Stealth Branch
Always do your stealth work on a branch that starts with `shadow/`.

```bash
git checkout -b shadow/feature-x
```

## 3. Exporting Work (PC 1)
Run this command to create a bundle of your stealth branch:

```bash
# Packages the 'shadow/feature-x' branch into a portable file
git bundle create stealth_sync/shadow_work.bundle shadow/feature-x
```

## 4. Importing Work (PC 2)
Move the `shadow_work.bundle` file to the same `stealth_sync/` directory on the second PC, then run:

```bash
# Verify the bundle
git bundle verify stealth_sync/shadow_work.bundle

# Import the branch
git fetch stealth_sync/shadow_work.bundle shadow/feature-x:shadow/feature-x

# Switch to it
git checkout shadow/feature-x
```

## 5. Security Checklist
- [ ] **NEVER** run `git push origin shadow/...`
- [ ] **NEVER** add the `.bundle` files to a commit (they are ignored by the `stealth_sync/` rule in `.gitignore`).
- [ ] **DELETE** the bundle file once the sync is successful.
